# Mente Inabalável Experience — Landing Page

Estrutura inicial baseada na referência visual enviada.

## Arquivos

- `index.html` — estrutura da landing page.
- `style.css` — estilos e responsividade.

## Vídeo

O primeiro bloco contém um placeholder "VÍDEO AQUI".

Para substituir pelo vídeo, troque:

```html
<div class="video-placeholder">
    ...
</div>
```

por algo como:

```html
<video class="hero-video" controls poster="img/capa-video.jpg">
    <source src="video/video.mp4" type="video/mp4">
</video>
```

Depois, adicione os estilos necessários para `.hero-video`.
